# 73Haber WordPress Browser Bridge

Bu depo, 73haber.com.tr uzerinden hazirlanan haberleri GitHub Actions icindeki headless Chrome ile WordPress tarafina iletmek icin kullanilir.

- Cron tetikleme: cron-job.org -> 73haber.com.tr/x.php
- Hazirlama: RSS + Groq -> bekleyen is
- Tarayici: GitHub Actions -> headless Chrome
- Hedef: sirnak.iblogger.org/bot.php

Bu depo gizli anahtar veya Groq API anahtari icermez.
